# 🚗 Moving Car Animation

A simple forward-moving car animation built with **HTML**, **CSS**, and **JavaScript**. The project features a realistic scene with a background, road, and sky.

## 🌄 Preview

![Car Animation Preview](./car2.png)

> Ensure `car-preview.png` is in your project root. You can replace this with a real screenshot of the animation.

## 🎨 Features

- Car moves straight forward (not side to side)
- Styled background with road and sky
- Lightweight and beginner-friendly
- No libraries or frameworks used
